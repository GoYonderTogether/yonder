# 第三轮：主人对产品方向 Q1–Q6 的回答（2026-10-27）

1. 开源边界：统一客户端开源，放进公开主仓，装上就能直接用。AI 时代闭源不构成壁垒，只闭源后端逻辑（云端账号、社交、中转等服务端），其余几乎全部开源。
2. Card 社交和本机控制台是同一个应用，不是两个。
   - 按设备、场景、登录状态，用清单或分维度的判断逻辑决定显示哪些功能；工作台的大部分功能多端都能显示；登录后才出现社交功能。
   - Bot 模式：Bot 以 personal agent 的形式出现，每个 Agent 有自己的职能（对应 Card 社交）。
   - 控制台模式：类似 WorkBuddy，在本机或远程执行具体任务。
   - 两种模式要联动：Bot 能看到所有工作 session，能主动给用户提建议、帮用户整理这些 session。
3. 远程控制先上线，端到端加密是很久以后的事，不作为前置条件。
4. 默认配置：
   - 本机 pi agent 及本机已装的插件，装好后都可用。
   - 用户只需要配置模型。第一个 Bot（默认管家 Bot）由产品预先配好，基础功能全部初始化好。
   - 优化初始化插件：首次安装后，管家 Bot 按清单逐项排查、建立 task list，带用户把产品功能全部走通。
   - 本机能配置的渠道默认装上。微信、飞书、QQ、GitHub 等可插拔渠道随产品提供，但默认不包含，由用户选择并配置。
5. 分发：保留一条命令安装；同时作为开源项目在 GitHub 分发安装包，支持 Linux、macOS、Windows 多种安装方式。
6. 命名：产品家族统一叫 Yonder，命名统一由 Opus 负责，可参考 pi 生态的命名方式。
7. hermes-experience 重名问题主人没有回答，由 Opus 决定。
