# 页面清单（待审核）

目标：用最少的页面支撑"分享"和"聊天"。基于 [foundation.md](foundation.md) 的倾向（Tinode 网页端分支），聊天相关的页面直接复用，只新增四个。

## 1. 第一版（P0）

| # | 页面 | 登录 | 来源 | 作用 |
|---|---|---|---|---|
| 1 | 登录与注册 | — | 复用 | 邮箱加密码；不验证邮箱，不发验证码 |
| 2 | 聊天主界面：会话列表 + 会话页 | 需要（访客为匿名账号） | 复用 | 手机上是两屏，桌面是左右两栏；文字、图片、文件、Markdown、转发 |
| 3 | 个人资料 | 需要 | 复用 | 头像、姓名 |
| 4 | **名片页** `/u/<id>` | 免登录 | 新增 | 头像、姓名、名片正文、可选展示卡片、Agent 在线状态；按钮"和 TA 聊天""拥有自己的 Agent" |
| 5 | **名片编辑与发布** | 需要 | 新增 | Markdown 编辑与预览、资源、展示卡片；发布；分享区（二维码、链接、名片图） |
| 6 | **连接 Agent** | 需要 | 新增 | 确认某个 Agent 接入我的账号；列出我的 Agent 和在线状态 |
| 7 | **安装入口** | 免登录 | 新增（静态） | 复制安装提示词；也出现在名片页底部 |

访客从名片页点"和 TA 聊天"，自动创建匿名账号并进入页面 2。

## 2. 随后（P1）

| # | 页面 | 来源 | 作用 |
|---|---|---|---|
| 8 | 联系人与加好友 | 复用 | 按 ID 或扫码添加，我的二维码 |
| 9 | 建群与群成员 | 复用 | 创建群、拉人、把自己的 Agent 拉进群 |
| 10 | 通知与审批 | 复用并小改 | Agent 为自己的名片请求上线时，用一条带按钮的消息提示主人去审核 |

## 3. 主流程怎么走过这些页面

**主人**：在 Agent 对话里说"起草名片" → Agent 推送草稿，回一个链接 → 打开页面 5 预览、发布 → 在分享区拿二维码和链接 → 发到社群。

**访客**：扫码 → 页面 4 → 点"和 TA 聊天" → 页面 2 → 想自己拥有一个就进页面 7。

**Agent 接入**：装插件、登录 → 浏览器打开页面 6 确认 → Agent 出现在会话列表里。

## 4. 请你审核

1. 页面 4、5、6、7 是否就是你想要的最小集合。
2. 页面 3（个人资料）和页面 7（独立的安装入口）是否保留。
3. P1 的顺序是否要调整，比如建群是否比加好友更早。
