# 设计规约

改界面前先读本页。颜色、字号、圆角、动效只用 `src/styles.css` 里的令牌，页面里不写字面量。

## 参照与取舍

| 来源 | 取了什么 | 没取什么 |
|---|---|---|
| AI-Being（本机 `AI-Being/docs/product/design-principles.md`、`web/src/styles/tokens.css`） | 三层明度（竖栏 → 列表 → 内容）靠明度差分层；圆角只有几级；字号刻度化；手机触摸区 ≥ 44px、safe-area；桌面三栏尺寸（列表 320，消息列最大 760） | 紫色强调（与"AI 助手紫"撞车）；圆体字；18px 大气泡；到处出现的强调色 |

## 设计语言

**一句话：薄雾灰底上的白色纸面，黑白为主，圆润通透。** 主页风格参照 tasteskill.dev：暖灰雾底、柔和白卡片、黑色胶囊按钮、紧凑的粗体大标题。聊天应用的主角是对话，界面退后；不锁定任何色相，强调就是墨色本身（亮色里是黑，暗色里是白）。

- **色彩**：薄雾灰底（#efeeeb 一族）+ 纯白纸面（桌面上内容区是带 24px 圆角和柔和阴影的白色面板，浮在雾底上）；墨色近黑；强调色 = 墨色。红色用于危险操作或明确的执行阻塞，二者用文案区分。头像用无彩度的灰调。
- **分层**：靠明度差，不靠线。竖栏最深，列表次之，内容最亮。发丝线只在输入框聚焦环和少数表格里出现。
- **阴影**：只用柔和大半径阴影，给纸面、选中的列表行、输入条、菜单；不用硬投影。
- **圆角**：控件 10，卡片 16，气泡 16（同一发送者连续消息的相邻角收到 6），按钮 full。一个按钮形状：胶囊。
- **字体**：Geist Variable（英文数字）+ 系统中文（苹方 / 思源黑体）；代码用 Geist Mono。只有这两个家族。
- **字号只有五档**：12（说明）· 14（列表、次级）· 15（正文、聊天）· 20（标题）· 32（展示，名片名字与登录）。展示字间距 −0.03em，行高 1.05。
- **正文**用满墨色，灰色只用于次级信息。行宽 45–75 字符，聊天列最大 720。
- **对齐**：默认左对齐。
- **文案**：句首大写式的简洁中文；按钮写动作（"发布""保存草稿"），不写"提交"；错误说清原因和怎么办；空状态给出下一步。

## 布局

| 断点 | 结构 |
|---|---|
| 手机 < 768 | 单列。会话列表是首页，底部标签栏（消息 / 名片 / Agent / 我）；进入会话全屏，隐藏标签栏，左上返回。 |
| 桌面 ≥ 768 | 竖栏 64 · 列表 320 · 内容自适应。设置类页面（名片、Agent、我）占内容区，内容列最大 720。 |
| 名片页 ≥ 1024 | 左右两栏：左 320 是身份（头像、名字、状态、二维码、聊天按钮），吸顶；右侧是展示卡片和正文。手机上叠成一列，聊天按钮吸底。 |

- 外边距 16（手机）/ 24（桌面），间距 4 的倍数。
- 根布局不滚动，只有列表、消息、内容区自己滚动。
- 手机触摸区 ≥ 44px；底部用 `env(safe-area-inset-bottom)`。

## 动效

只动 `transform` 和 `opacity`。

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ease` | `cubic-bezier(0.22, 1, 0.36, 1)` | 所有进入与状态变化 |
| `--d1` | 120ms | 悬停、按下、颜色 |
| `--d2` | 200ms | 消息、行、面板进入 |
| `--d3` | 360ms | 名片页进入 |

- **消息进入**：从下方 8px 渐显，只对新消息。
- **输入中**：三个点依次起伏，Agent 回复前出现。
- **按下**：控件缩到 0.97。
- **在线点**：在线时一圈缓慢外扩的光环（2.4s），离线静止。
- **名片页进入**：身份与内容错开 60ms 依次升起，只在载入时一次。
- **骨架**：加载列表用透明度脉动的骨架行，不用转圈文案。
- **减弱动效**：`prefers-reduced-motion` 下去掉位移，保留渐显；内容在脚本失败时也可见。

## 组件规则

- 选中的会话行：变成白色小卡片并带柔和阴影；未读是黑色小胶囊；竖栏当前页有黑色竖线指示。
- 我的气泡：黑底白字（暗色里反过来）；对方：浅灰底，无描边。
- 输入条：浮起，圆角 20，无描边，聚焦时 2px 强调色环；发送按钮圆形强调色。
- 表单字段：灰底、无描边，聚焦出强调色环；标签在上，13 号次级色。
- 离线 Agent 的提示放在输入条上方，一行，次级色。

## 验收

- 浅色与深色，宽度 390、768、1280 各看一遍。
- 键盘可达：每个交互元素有可见聚焦环。
- 减弱动效下无位移。
- 颜色、圆角、字号没有字面量（`grep` 检查）。

## 色彩与状态（克制版）

**界面以黑白为主，彩色限于头像、连接可用性与有真实数据的执行语义。**

- **Agent 头像**：圆角方形的柔和渐变球（纯 CSS，不画 SVG），色相从固定的一套 6 个里按 id 取：`18 · 52 · 160 · 205 · 255 · 315`，明度与彩度统一。人的头像是灰调首字，不上色。
- **品牌 Agent 的头像**（以后接入 Claude、Codex、Hermes 等时）：用 [Lobe Icons](https://github.com/lobehub/lobe-icons)（MIT，Agent HUD 也用它）里对应的品牌图标，不自己画。
- **连接状态规范**，不跟任何主题色：绿色 = 在线，灰色 = 离线；**没有状态就不显示**（人没有在线点，设置页不写"无"）。状态点 10px，叠在头像右下。
- **执行语义与连接分离**：本机 Harness 的运行/自动重试为黄、执行阻塞为红、待检查为蓝、无执行为灰；输入等待用灰色并写“等你”，未知须明确标明。颜色必须配文字，不能从在线/离线推断执行状态。本互联网网页当前仅有 `online` 连接字段，尚未接入执行 API，不展示或推测上述执行灯。
- **氛围**：只在名片页顶部，一块极大、极淡的色块（Agent 头像同色相，不透明度约 16%，模糊 60px，向下渐隐），不动。
- **光点**：名片页顶部 6 个 3px 的灰点，5 秒一次缓慢明灭，减弱动效下静止。
- **不做**：气泡染色、会话光晕、跟随主题色的在线点、用户选主题色、登录页和空状态的装饰。
