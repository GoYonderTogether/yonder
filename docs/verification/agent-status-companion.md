# Agent 状态与固定悬浮入口

基于 main 71920ca，候选版本 0.2.26102505。

- service.info 增加 agents；按未归档 Agent 聚合原生 LiveDoc、inbox、后台任务与上下文整理，不依赖 UI 卡片判定是否工作。只读当前输入摘要和生成中的 text 块，不返回 thinking、工具参数或输出。
- 唯一状态栏后台每 2 秒读取，并在菜单打开时刷新；读取失败显示未知。菜单显示各 Agent 的任务摘要及短回复；打开悬浮窗取代当前交互，左右键仍统一菜单。
- 桌面宿主通过原有 WK 桥提供概览；插件 SDK 权限不变。图钉按 home 保存，固定后收起保留同锚点悬浮入口；鼠标离开且无输入/拖动时自动收起。等待交互与空闲有独立标记，减少动态效果时关闭呼吸。默认完成自动收起，autoClose:false 完成结果与内嵌承载保留。
