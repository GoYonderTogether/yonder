# 微信双插件迁移验收

日期：2026-10-21。原始目标：将 AI-Being/旧 being 的微信归档与 iLink 代码和功能迁入两个 Yonder 插件，说明真实 Bot 的工具入参/出参，并实现首个 iLink 实例默认主人、其他实例独立身份。

## 实现

- 原生插件 wechat-archive（7 工具 + 资料触发器）、channel-wechat-ilink（3 工具 + 渠道）。仅依赖 SDK、标准库和明确功能依赖 typebox/silk-wasm；不 import 旧宿主或 pi。
- 资料与交互分开，事件/绑定/身份/profile/投递均走 Yonder 现有入口；私密归档与登录工具对受限联系人不可发现。
- 工具/配置/真实场景：[归档](../../plugins/wechat-archive/README.md)、[iLink](../../plugins/channel-wechat-ilink/README.md)。
- 不搬生产凭据或微信正文，不安装/替换日用程序，不发布。
