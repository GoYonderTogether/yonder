# 16 执行能力补齐

2026-10-19 用户批准直接实现、并行派工及发版。本规范覆盖旧条款相冲突部分；不扩展记忆引擎、沙箱或人格预设。

## 1 内核异步执行与时间感知

工具运行超过15秒自动返回真实后台句柄，不取消原任务、不阻塞后续模型工作。后台句柄按调用session隔离；提供状态、增量日志、等待、输入和取消能力。完成与失败保留真实结果并以原生输入通知原session；仍在运行时在工具间隙steer，闲置时显式继续原任务，不伪装成用户发言。仅程序展示通知另走sessions.notify，不冒充模型已处理。结束结果落盘，内存不无限保存日志/已结束句柄；清理内存不删除会话、用户文件或持久结果。重启不能恢复的外部调用明确标记中断，不自动重放有副作用操作。主动abort/close/shutdown取消所拥有的后台工作，不能遗留无主进程。

bash增加background/yield、进程日志/输入/结束管理，保持命令、cwd、退出码和stderr语义。可交互进程使用原生管道；未提供PTY不得标称PTY。通用工具均走共享异步边界，不能只修bash而阻塞task_run或插件工具。权限校验和hook仍在原调用链，不增加另一层授权。

原limits.maxMinutes/maxTurns改为软提醒阈值，可增加maxTokens提醒；超阈值记录运行事实，提醒本session，子任务同时告知父session，不abort、不改成limit终态。真实模型输入/输出限制、显式取消、安全拒绝和防重复空转仍有效。提醒去重，不为每条日志唤醒模型；时间事实在正常请求时更新，不依赖额外轮询模型。配置已设数值沿用为提醒阈值。

## 2 cron插件

官方独立插件cron，不把调度逻辑放内核。采用成熟cron解析库处理5/6字段表达式、IANA时区/DST、范围/列表/步长、一次性at、固定间隔every。支持创建/读取/列出/修改/启停/删除/立即运行/运行历史、有限次数与起止窗口、重启后过期任务合并补跑或跳过、同job不重叠、并发限制。调度持久化在插件data，执行记录与事件可追溯；未知副作用不自动重试。

payload支持原始事件（沿既有Agent绑定唤醒）、指定preset隔离任务，以及无模型命令/脚本。目标和时区必须明确；无模型仅在exec调用方创建，不能用事件/调度提升权限。直接程序输出可发明确渠道目标，模型结果使用真实run结果投递。调度失败、运行失败、投递失败分别记录。服务启动后恢复调度，停服释放timer/自有子进程。不得宣称macOS休眠/关机期间运行。复杂调度以这些原语组合，不另造工作流DSL。

## 3 MCP客户端插件

官方独立mcp-client复用已安装官方MCP SDK，支持stdio与StreamableHTTP（及SDK SSE兼容入口）、持久连接、按需连接/重连、发现/调用工具、资源列出/读取、prompt列出/获取、状态/断开。配置服务或经工具显式连接，作用域明确；工具名保留server和原名，不一次常驻注入所有schema。server instructions/prompts是外部资料，只在所选上下文/工具结果按来源呈现，不能升级为系统安全规则。

stdio需要exec，HTTP需要network，返回给模型的通用调用保守保留服务对应能力边界；不能让readonly借MCP越权。凭据沿credentials引用，禁止回显secret。连接失败给具体诊断；重连不重放未知结果工具。取消沿signal，关服清连接/子进程。OAuth使用SDK现有协议或返回真实待授权信息，不复制其他客户端账号。

## 4 Agent热管理

采用docs/tasks/agent-template-proposal.md的A0–A4：稳定id/name/work分离，preset生成合法配置，注册/agent/preset统一校验后热发布，失败保留旧有效状态。CLI复用management RPC，增删改查/归档恢复及preset管理，不提供真删。归档不接新输入，已有任务不强制abort，保留工作区和转录；默认主Agent归档需先指定活动默认目标。开放会话保护workspace/env/profile。现有插件/provider/服务等仍不热加载。只把确实安全唯一的规范化放解析器，不建立自动纠错模型。

## 5 浏览器和桌面替代插件

保留BrowserSkill与Codex桥接。另提供独立browser/desktop工具，不要求这两项安装；优先直接采用Hermes/OpenClaw可复用原生方案和许可。自动探测本机原生浏览器/OS能力，能自动启动即启动。浏览器需要的浏览器引擎/驱动应随依赖或由显式安装流程准备，不宣称无任何依赖；macOS桌面仍须系统屏幕录制/辅助功能授权，不能绕过。无宿主凭据可完成本地网页操作/截图/键鼠即为替代闭环。原始实现和版权注明来源，不引入另一Agent运行核心。

## 6 手工memory目录

Agent workspace允许普通文件工具创建memory目录、按日期/条目保存及索引资料；初始化提供memory/README.md说明用途、来源、日期与事实/假设区分。仅按需读取，不新增上下文贡献、不自动注入、不自动总结/删除/清理。说明必须指出这只是临时记录约定，需结合真实场景参考成熟方法迭代，不能将简单目录当作长期记忆引擎。不得覆盖现有用户目录或文件。
